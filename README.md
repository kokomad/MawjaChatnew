# موجة شات - MawjaChat

تطبيق أندرويد للتواصل الصوتي الخاص عبر تحويل الرسائل الصوتية إلى مخطط موجي دقيق يرصد الحروف، الكلمات، فترات السكون، والفراغات، ويرسلها للطرف المقابل عبر قناة خاصة محمية بـ (اسم المرسل + اسم المستقبل + الكود المشترك) ليقوم المستقبل بتحليل الموجة وإرجاعها إلى ملف صوتي قابل للتشغيل والحفظ بصيغة WAV.
